# 💰 Keuangan Pribadi

Aplikasi pengelolaan keuangan pribadi sederhana berbasis web.

## ✨ Fitur
- Catat pemasukan & pengeluaran
- Dashboard ringkasan saldo
- Grafik pengeluaran per kategori
- Target tabungan dengan progress bar
- Filter transaksi per kategori
- Laporan bulanan sederhana
- Data tersimpan di localStorage

## 🚀 Cara Pakai
1. Buka `index.html` di browser
2. Mulai tambahkan transaksi lewat tombol **Tambah**
3. Data otomatis tersimpan di browser Anda
